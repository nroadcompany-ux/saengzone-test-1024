# 생ZONE - TEST 1024

**TEST / Candidate — 기존 운영 서비스와 독립된 실험 저장소**

## 목적
생ZONE 창업 준비 앱 홈의 서비스 아이콘 직접 노출 구조를 검토합니다.

## 범위
- 홈 4개 임시 그룹 × 8개 서비스 아이콘(총 32개 후보)
- 아이콘명 검색 및 클릭 테스트 안내
- 하단 메뉴 홈 / 로드맵 / 투데이 / 혜택 / 커뮤니티 (시각 표시만)
- 외부 서비스·로그인·결제·고객정보 연결 없음

## 운영 통제
- 기존 생ZONE v7 및 Plus 저장소의 코드·브랜치·배포를 변경하지 않습니다.
- 이 저장소의 내용은 공식 Foundation 또는 최종 제품 구조가 아닙니다.
- 현재 저장소는 **Public**이며 공개 자료만 취급합니다.
- 실제 서비스 URL, 사용자 추적, 데이터 연동은 추후 승인 대상입니다.

## 실행
`index.html`을 브라우저에서 열면 됩니다. 빌드 과정이 없는 정적 HTML입니다.
